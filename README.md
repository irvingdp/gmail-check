# Gmail 收件者檢查 (Chrome 擴充功能)

在 Gmail 撰寫郵件時，如果「收件者」(To) 欄位是空的，就不能傳送，即使「副本」(CC) 或「密件副本」(BCC) 已經有填。

## 擋下的動作
- 點「傳送」按鈕（按鈕會變灰，滑鼠移上去會顯示提示）
- 「傳送」旁的下拉箭頭（排程傳送）
- 鍵盤 Ctrl+Enter / ⌘+Enter
- 焦點在傳送按鈕時按 Enter / 空白鍵

支援多個撰寫視窗、彈出視窗、以及在信件中直接回覆 / 轉寄。

## 安裝（載入未封裝項目）
1. Chrome 開啟 `chrome://extensions`
2. 右上角打開「開發人員模式」
3. 點「載入未封裝項目」，選這個資料夾 `gmail-check`
4. 重新整理 Gmail 分頁

修改程式碼後，在 `chrome://extensions` 按這個擴充功能的重新整理圖示，再重新整理 Gmail。

## 測試
1. 撰寫新郵件，只在「副本」填一個地址 → 「傳送」應變灰，點了會出現紅色提示，不會寄出。
2. 在「收件者」填一個地址 → 「傳送」恢復正常。
3. 試 ⌘+Enter、回覆、轉寄、同時開兩個撰寫視窗。

## 備註
- 判斷方式是找撰寫視窗中 `name="to"` 的欄位與其中的收件者標籤，不依賴中文文字，換語言也能用。
- 如果 Gmail 改版找不到收件者欄位，擴充功能會「放行」而不是擋住，避免你完全不能寄信。若遇到這情況請回報。
